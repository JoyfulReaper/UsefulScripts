## Re-creatable — do not waste backup space

Generally do not back up:

* Docker images
* container writable layers
* Docker bridge networks
* BuildKit caches
* apt caches
* logs unless deliberately desired
* system package databases
* `/var/lib/docker` wholesale

Docker containers and networks should be recreated from Compose rather than restored as opaque Docker internals.

## Inventory gap: tcpnoise

`tcpnoise` is actively listening on numerous public ports including 21, 23, 420, 2222, 2323, 3389, 5432, 8080 and 42069, but it does not appear in either the running systemd-service list or the Docker container inventory.

Its startup mechanism therefore needs to be identified and documented.

## Restore order

1. Provision Ubuntu host.
2. Restore SSH access and host identity/secrets.
3. Install Docker, WireGuard, Yggdrasil, nginx, Cloudflared and BIRD.
4. Restore `/etc` configuration and custom systemd units.
5. Restore Compose files and `.env` files.
6. Restore bind-mounted persistent data.
7. Restore Docker named-volume contents.
8. Start infrastructure services.
9. Start Compose projects.
10. Verify WireGuard/Yggdrasil/DN42 routes.
11. Verify public and VPN-only listeners.
12. Test databases and application health.
