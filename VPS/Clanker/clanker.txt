CLANKER
=======
Infrastructure / Recovery / Service Overview
Snapshot date: 2026-09-21

PURPOSE
-------
Clanker is Kyle's primary always-on Ubuntu VPS and currently acts as a mixed
application host, protocol server, VPN/router, observability node, overlay-network
node, and DN42 router-in-preparation.

This file is intended to answer:
- What is Clanker?
- What runs here?
- What starts it?
- Where is its configuration?
- Where is persistent data?
- Which secrets matter?
- What network does it participate in?
- What would be needed to rebuild it?
- What have we NOT inventoried yet?

It is deliberately broader than a backup manifest.

===============================================================================

    Clanker ------> ScopeCreep
       \              /
        \            /
         ---> R2 <---

Possible reciprocal local/off-host snapshots:
    Clanker backs up to ScopeCreep
    ScopeCreep backs up to Clanker

Important:
    Treat these as snapshot repositories, NOT mirrors.
    Avoid destructive sync semantics such as blind rsync --delete.

Potential third copy:
    Cloudflare R2 free-tier object storage

Potential repository format:
    Restic or similar encrypted, deduplicated snapshot repository.

    Historical retention.
    Possibly bucket-lock/immutability for a separate protected tier, after checking
    compatibility with repository maintenance/pruning.
